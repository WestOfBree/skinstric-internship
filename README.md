# Skinstric Internship Project

Skinstric is an interactive AI skincare experience built as a modern frontend portfolio project. The app guides users through a multi-step analysis flow where they enter profile details, upload or capture a face image, and review AI-estimated demographic insights through a polished, animated interface.

This project was designed to showcase both product thinking and frontend engineering: building a guided user journey, integrating external AI endpoints, handling browser media and file APIs, and presenting returned data in a clean, responsive UI.

## Project Summary

This application demonstrates how to create a user-focused AI workflow in the browser using Next.js, React, and TypeScript. Users move through a structured analysis experience that includes profile input, camera permission handling, image upload or live capture, API-powered analysis requests, and result interpretation through interactive selectors and progress visualizations.

The experience emphasizes responsive layout, state-driven transitions, accessibility-aware form interactions, and client-side persistence so the flow remains smooth across multiple steps.

## Technologies Used

- Next.js 16 with the App Router
- React 19 functional components and hooks
- TypeScript for type-safe component and state logic
- Tailwind CSS 4 for responsive styling and layout
- Axios for external API communication
- Browser APIs including `localStorage`, `FileReader`, `canvas`, and `navigator.mediaDevices.getUserMedia`
- ESLint for code quality and consistency

## Skills Showcased

- Building a multi-step user flow with clear client-side state management
- Integrating third-party AI APIs and handling async request states
- Working with camera access, file uploads, and image capture in the browser
- Persisting data across screens with reusable storage utilities
- Transforming nested API data into UI-friendly summaries and scores
- Creating reusable, modular React components for navigation, popups, selectors, and visual feedback
- Designing responsive, interaction-heavy interfaces with Tailwind CSS
- Applying accessibility-minded patterns with semantic HTML, labels, and keyboard-friendly form behavior

## Highlights

- Guided AI skincare analysis journey from onboarding to summary
- Dual image input flow: upload from gallery or capture from the device camera
- Animated diamond-based UI system for a distinctive branded experience
- Client-side storage to preserve profile and image data across steps
- Summary screen that maps returned analysis data into readable demographic indicators
